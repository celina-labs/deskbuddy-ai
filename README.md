# DeskBuddy OS

DeskBuddy ist ein kleiner Schreibtischroboter, den ich auf Basis eines ESP32-S3 gebaut habe.

Aktuell hat er ein animiertes Gesicht auf einem OLED-Display, eine Touch-Steuerung, einen Pomodoro-Timer sowie Sitz- und Steherinnerungen. Über ein Mikrofon kann außerdem eine Sprachaufnahme gestartet und verarbeitet werden. Die Antwort wird direkt auf dem Display angezeigt.

Beim Zusammenbauen hat sich gezeigt, dass das Gehäuse für den ursprünglich geplanten Lautsprecher zu klein ist. Deshalb habe ich den Lautsprecher und die Sprachausgabe wieder entfernt. Das Mikrofon bleibt im Roboter und die Antwort erscheint stattdessen auf dem Display. Später soll noch eine Weboberfläche dazukommen.

Das Projekt wird Schritt für Schritt weiterentwickelt und dokumentiert.
